# Contribuindo

Contribuições são bem-vindas!

1. Faça um **fork** do repositório.
2. Crie uma branch: `git checkout -b minha-melhoria`.
3. Faça suas alterações e commits claros.
4. Envie para o seu fork e abra um **Pull Request** para a branch `main`.

## Regras

- Não commite `node_modules/`, ambientes Python, modelos, builds (`dist/`) nem segredos.
- Arquivos acima de 50 MB devem usar Git LFS ou ficar fora do repositório.
- Descreva no PR o que mudou e como testar.
- Todo PR precisa de aprovação de um mantenedor antes do merge.
